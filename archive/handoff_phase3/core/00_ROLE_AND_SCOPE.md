# 00 — Role, Scope, and Non-Goals

## Role

You are the implementation and empirical-analysis agent. The reasoning decision has already been made: the next step is a bounded structural-separability study, not another architecture discussion.

Inspect the repository and adapt this specification to the actual schema and file layout, but preserve the scientific intent. Record any material mismatch between this package and repository reality.

## In scope

1. Reconstruct one or more graph views from existing exact MathRecord outputs.
2. Audit graph coverage and extraction-boundary effects.
3. Compute reproducible graph features.
4. Test no-name structural separability of existing infrastructure classes.
5. Test theorem-local landmark ranking on a small, preselected proof sample.
6. Produce compact user and agent review packets.
7. Reconcile current-direction documentation without rewriting historical reports.

## Out of scope

- Replacing Lean or changing the verification boundary.
- Building a universal graph database.
- Materializing all possible theorem applicability edges.
- Training a large GNN or language model.
- Scaling to all of Mathlib before the bounded study is interpretable.
- Treating P3’s unclassified residue as established mathematical content.
- Treating non-machinery as synonymous with landmark.
- Promoting a new persistent ontology solely because a classifier performs well.
- Solving definition generation, conjecturing, real-world application navigation, or global proof search in this phase.

## Scientific posture

The likely useful output is a **probabilistic structural-role score**, not a perfect binary partition.

Topology may identify recurring formal roles. It cannot be assumed to determine usefulness independent of theorem, proof state, representation, or task.
