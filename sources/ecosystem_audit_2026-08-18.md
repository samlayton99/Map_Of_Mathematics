## Notes per tool

1. **lean4export** — Now NDJSON, not the old whitespace format (`format_ndjson.md` in repo). Flags: `--export-unsafe`, `--export-mdata` (mdata stripped by default). Explicitly kernel-level: no source locations, no tactic traces, no local proof states. Actively tracked against each Lean release. https://github.com/leanprover/lean4export
2. **repl** — Community-maintained, bumped within a day of each toolchain. Key limitation for representation work: tactic states are strings, not terms; key strength: cheap pickling/restore of environments and proof states. https://github.com/leanprover-community/repl
3. **LeanDojo v1** — Officially deprecated Jan 2026; v2 (actively maintained, Aug 2026 commits) is the successor and delegates interaction to Pantograph. https://github.com/lean-dojo/LeanDojo, https://github.com/lean-dojo/LeanDojo-v2
4. **Pantograph/PyPantograph** — The richest structured interface audited: per-goal/per-hypothesis JSON with optional sexp AST of every expression (`Expression.sexp?`), state save/load, sorry-based drafting, structured failure messages. Pin lags Lean (v4.31.0). https://github.com/stanford-centaur/Pantograph (doc/repl.md, Pantograph/Protocol.lean), https://github.com/stanford-centaur/PyPantograph
5. **lean-training-data / ntp-toolkit** — InfoTree-based; give source-anchored tactic transitions but goals only as pretty-printed text. Both lag current Lean (v4.16.0 / v4.24.0); commit activity slowed late 2025. https://github.com/kim-em/lean-training-data, https://github.com/cmu-l3/ntp-toolkit
6. **Lean core** — v4.33.0 stable (2026-08-10). Note: one web summarizer initially misreported the year as 2024; cross-checked via commit timestamps of same-day toolchain bumps in lean4export/repl (both 2026-08-10/11), confirming 2026. https://github.com/leanprover/lean4/releases
7. **Newer tools found (2025-2026 search)** — Besides LeanTree: LeanExplore (declaration search engine, arXiv 2506.11085), AXLE cloud infra with `extract_decls` (per-declaration name/kind/signature/body/source-line-range/deps, arXiv 2606.26442), LeanSerde (general Lean serialization lib, updated Mar 2026), and a proof-state snapshotting paper (arXiv 2605.25556). Nothing from Harmonic/Math Inc/kimina surfaced as a public extraction tool in these searches.

Caveat: PyPantograph's docs site (centaur.stanford.edu/PyPantograph) returned an empty page on fetch; its details above come from the GitHub README and the Pantograph protocol source instead.
